# CQ
This repository is the code behind CQ, a Hack Club YSWS.
This is coded in Node JS. 

## Development
To run this locally, you will need Node.js 22.12.0 or later.

```sh
npm install
cp .env.example .env
npm run dev
```

To use this without Auth (for local previews) set `DEV_AUTH_BYPASS=true` in `.env`.
The tests can be run with `npm test`.
